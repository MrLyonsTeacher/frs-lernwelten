# FRS Lernwelten

Interaktive Lernwelten für iPads – ohne Anmeldung, über QR-Codes.

- **Startseite für Lehrkräfte:** `index.html` – Klasse wählen, QR-Code zeigen
- **Ergebnisse einsammeln:** `ergebnisse.html` – Ergebnis-Codes scannen, Klassenübersicht
- **Englisch-Klasseninseln:** `englisch/insel.html?k=5` … `?k=10`
- **Katalog aller Lernwelten:** `katalog.js`
- **Escape Rooms:** Ordner `escape/` (Vulkan `escape/vulkan.html`, Der Schwarm `escape/schwarm.html`, Verbindungstest `escape/test.html`, Vermittlungsdienst `escape/relay/`, Einrichtung siehe dort)

Alle Ergebnisse werden nur lokal auf den Geräten gespeichert.


**Rätselfamilien der Escape Rooms** (`escape/pool.js`, `FAMILIES`): Zahlen & Codes (Vulkan, Der Schwarm), Logik & Detektiv (Bibliothek, später Eiswelt), Sehen & Raum (Wrack, später Drachenhöhle), Team & Sinne (Finlorién, ein weiterer Raum). Jeder Raum zieht etwa drei Viertel seiner Rätsel aus seiner Familie.
